# Task Prompt for Claude Code

## What to tell Claude Code

Copy-paste the block below into Claude Code as your prompt. Make sure the three PDF files and `EXTRACTION_INSTRUCTIONS.md` are in your repo root first.

---

```
Read EXTRACTION_INSTRUCTIONS.md thoroughly — it contains the full specification for this task.

I need you to extract every Sanskrit verse from three scanned PDFs of the Samaranganasūtradhāra Volume 2. The PDFs are:

1. Samarangan_Vol2_Chapters_55-60.pdf → Chapters 55–60
2. Samarangan_Vol2_Chapters_66-67.pdf → Chapters 66–67  
3. Samarangan_Vol2_Chapters_71-72.pdf → Chapters 71–72

For each PDF, produce a separate Markdown file containing every verse from the target chapters. Each verse needs:
- Devanagari (read visually from the scanned page images)
- IAST transliteration (generated by you)
- English translation (copied verbatim from the page)

Use the extract_verses.py script to automate this. The script:
1. Rasterizes each PDF page into a JPEG
2. Sends it to Claude Sonnet 4.6 via the API with the extraction prompt
3. Appends the result to the output markdown file
4. Checkpoints progress so it can resume if interrupted

Steps:
1. Install dependencies: `pip install anthropic pdf2image Pillow`
2. Make sure `poppler-utils` is available (for pdftoppm)
3. Run: `python extract_verses.py --pdf-dir . --output-dir ./output`
4. If it fails partway, resume with: `python extract_verses.py --resume-file N --resume-page M`
5. After completion, review the three output files in ./output/

The ANTHROPIC_API_KEY environment variable must be set.

Start by confirming the PDFs exist and dependencies are installed, then run the script. Monitor for errors and fix any issues.
```
